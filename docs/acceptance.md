## HTTP checks

The six router tests cover unauthenticated liveness, authentication rejection, body identity fields being ignored, trusted request IDs, state/history caller scope and cursor handling, wait bounds, stable `not_found` mapping, and a real deterministic course HTTP flow. The separate core suite covers Runtime ownership and auth guarantees; HTTP mock cases alone are not evidence for those guarantees.

The native production Mix release was verified over live localhost TCP and survived stopping/restarting the exact release process with the same SQLite database, using the deterministic adapter. The Docker image is also built and tested in local Kind with exact app-pod replacement and persisted checkpoint/history resume; its final Studio course used actual Luna through the authenticated host gateway. Compose was not started. All Kubernetes commands used the dedicated kubeconfig and explicit `kind-rutvi` context. Never use the `engeto-prod-v2` context for verification.
